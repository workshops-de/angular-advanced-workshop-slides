### Your playground

* Clone the repository from GitHub.
  * `git clone https://github.com/workshops-de/angular-advanced-workshop --branch main`
* Install the dependencies with _npm_.
  * `cd angular-advanced-workshop` 
  * `npm install`
* Start the application to verify everything is working
  * `npm start`

### Your API

* The example app needs an API to work correctly ([bookmokey-api](https://github.com/workshops-de/bookmonkey-api))
* You can install it globally (`npm i -g bookmonkey-api`) or run it directly `npx bookmonkey-api`
